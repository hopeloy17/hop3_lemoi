# hop3_lemoi

A small, hand-drawn art portfolio landing page.

Open `index.html` in a browser to view it. The page is dependency-free; its
background button cycles through ten colorways. Category petals filter the
archive, the nested shape opens the about section, and selecting the sketch pile
fans it apart around an artwork viewer. It opens on page one; swipe left to
advance and right to go back. Navigation stops at both ends. Clicking outside
or pressing Escape closes the viewer.

Artwork slots are intentionally marked as coming soon until real portfolio
images are added.
